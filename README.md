# 🥮 尋味嶺南：非遺小吃造物局 (Lingnan Heritage Snack Workshop)

> **港粵同源・四大非遺核心工藝・AI 與感應器互動教學 Web App**  
> 透過手機感應器（陀螺儀、麥克風、多點觸控）、AR 廚房實戰導航與 AI 視覺評分技術，掌握 12 款嶺南名小吃背後的「傳統匠人絕活」與「飲食科學 (STEM)」，看穿香港街頭小吃與大灣區（順德、中山、番禺、東莞、廣州、新會）一脈相承的血緣關係。

---

## ✨ 核心功能一覽

### 一、 四大非遺工藝工坊（12 款精選嶺南小吃）
1. **時光發酵坊（微觀與溫控）**
   - **包含小吃**：順德倫教糕（香港稱白糖糕）、廣式叉燒包（老麵發酵）、新會陳皮紅豆沙（陳化技藝）
   - **互動機制**：【溫濕度滑桿 + AR 微觀鏡】根據四季天氣調整發酵箱溫度，開啟微觀鏡觀察酵母菌產生氣泡，在乳酸酸度超標前精準截停，蒸出完美的「橫豎小水泡（豬膏眼）」。
2. **巧手木模坊（觸覺與力道）**
   - **包含小吃**：中山咀香園杏仁餅、廣式蓮蓉月餅、客家艾粄 / 茶果
   - **互動機制**：【壓感觸控 + 麥克風吹氣】控制按壓力道將綠豆粉夾冰肉心填入梨木餅印，點擊模擬木槌「敲模」震出餅坯，最後對著麥克風吹氣掃走多餘粉粒。
3. **流體撞擊坊（重力與節奏）**
   - **包含小吃**：番禺沙灣薑撞奶、順德雙皮奶、港式絲襪奶茶
   - **互動機制**：【手機陀螺儀（體感傾斜）】緊盯水牛奶溫度計，當降到黃金 75°C 瞬間，傾斜手機將牛奶從高處快速「撞」入薑汁碗中，並進行「湯匙浮面測試」。
4. **酥皮千層坊（手勢與火候）**
   - **包含小吃**：港式酥皮蛋撻、廣州雞仔餅（小鳳餅）、東莞糖不甩 / 煎堆
   - **互動機制**：【多點觸控摺疊 + 聽聲辨火候】以「三摺四轉」手勢疊出 $2 \times 3^4 = 162$ 層酥皮；炸煎堆時聽滋滋油聲辨油溫並畫圈淋油使其空心膨脹。

### 二、 三大核心創意亮點
- **亮點一：AI「非遺餅印」個人化設計器（賦權創作）**：輸入姓氏、校訓或祝福語（如「明信」、「仁愛」），自動生成配搭萬字紋、嶺南佳果紋的 3D 虛擬梨木餅印（陰刻反字）與蓋印杏仁餅/月餅成品，並可發佈至校園排行榜。
- **亮點二：「真・廚房」AR 實戰導航模式（高度實用性）**：支援開啟手機鏡頭或模擬桌面 AR 視角，投射半碗米漿、兩湯匙薑汁等真實材料比例，配備粵語智能語音朗讀與步驟計時器。
- **亮點三：「AI 大廚」視覺評分系統（AI 科技應用）**：上傳親手製作的倫教糕或杏仁餅照片（或選用內置實作樣本），透過視覺識別分析氣孔分佈與完整度，由虛擬「嶺南老師傅（陳師傅）」給出地道評語並解鎖可下載的《嶺南非遺小吃傳承人電子證書》。

## 🚀 如何部署到 GitHub Pages

1. 在 GitHub 建立一個新的公開儲存庫（例如 `lingnan-heritage-snacks`）。
2. 將本專案包解壓縮後，在資料夾內執行：
   ```bash
   git init
   git add .
   git commit -m "feat: 尋味嶺南非遺小吃造物局完整互動版"
   git branch -M main
   git remote add origin https://github.com/<你的GitHub帳號>/lingnan-heritage-snacks.git
   git push -u origin main
   ```
3. 進入 GitHub 儲存庫的 **Settings** ➔ **Pages**，在 **Build and deployment** 選擇 `Deploy from a branch`，分支選擇 `main` / `/ (root)` 並按 **Save**。
4. 等待約 1 分鐘，即可透過 `https://<你的GitHub帳號>.github.io/lingnan-heritage-snacks/` 在手機、平板或電腦瀏覽器直接體驗！
